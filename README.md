## 📖 核心价值与定位

**chatgpt指南** 不是传统的拼凑型营销博客，而是一个具备严格技术评测依据、结构化实体数据库与高效商业转化的 **现代化内容增长引擎**。

```
核心关键词 → 长尾搜索意图 → 垂直专题中心 → 深度实操指南 → 客观横向横评 → 官网安全转化
```

### 核心建设原则：
1. **一个域名，统一主题权威**：全站所有内容均服务于 AI、科学上网与网络排障核心心智。
2. **Answer-First 导语规范**：所有长尾文章与专题首页在首屏 100 字内直接给出可执行结论。
3. **真实测速与数据溯源**：31 家主流机场评测均附带测试基准、线路类型（IEPL/IPLC/公网中转）与晚高峰丢包实测。
4. **全端客户端覆盖**：Windows (Clash Verge Rev/v2rayN)、macOS、iOS (Shadowrocket)、Android 与 OpenWrt 软路由完整配置手册。

## ⚡ 技术架构与 SEO / GEO 特性

- 🚀 **100% 静态预渲染 (SSG)**：基于 Astro 5 纯静态构建，零服务端依赖，极速 TTFB (<50ms)。
- 🔍 **Pagefind 离线检索**：零第三方 API 依赖的客户端全文检索，即开即搜，不收集用户隐私。
- 🤖 **AEO / GEO 权威引用体系**：
  - 站点根目录部署 [`/llms.txt`](https://chatgptzhinan.homes/llms.txt) 与 [`/llms-full.txt`](https://chatgptzhinan.homes/llms-full.txt)。
  - 专为 ChatGPT Search、Perplexity、Google AI Overviews 与 Gemini 提供结构化事实问答。
- 🛡️ **安全转介防封体系**：
  - 独立中继路由 `/go/[slug]/`，自动附带专属立减优惠码 `AMM` 与本地点击遥测。
  - 严格隔离商业外链：全站 100% 自动包裹 `rel="nofollow sponsored noopener"`。
  - XML Sitemap 自动排除中继页，避免 Google Search Console 索引冲突。
- 📋 **交互式转化体验**：
  - 全局专属立减优惠码一键复制 + 毛玻璃 Toast 交互提醒。
  - 客户端轻量零 Cookie 隐私交互遥测。
- 🏅 **预防性 SEO 审计评分**：
  - **健康度评分：99.0 / 100 (A+ 顶尖级)**。
  - 0 内部死链、0 重复标题、0 重复描述、0 薄内容、0 JSON-LD 语法报错。

## 🛠️ 快速上手

### 环境要求
- **Node.js**: `v18.17.0` 或更高版本
- **包管理器**: `npm` / `pnpm`

### 1. 克隆仓库
```bash
git clone https://github.com/zlzlzl98698-dev/chatgptzhinan.homes.git
cd chatgptzhinan.homes
```

### 2. 安装依赖
```bash
npm install
```

### 3. 本地启动开发服务器
```bash
npm run dev
```
本地访问：`http://localhost:4321/`

### 4. 生产环境构建与索引
```bash
npm run build
```
此命令将自动执行：
1. `astro build` 生成 200+ 纯静态 HTML 页面至 `dist/`；
2. 自动生成规范的双格式 Sitemap (`sitemap-index.xml` & `sitemap.xml`)；
3. `pagefind` 遍历静态产物，构建本地多语言全文搜索索引。

### 5. 本地预览生产构建产物
```bash
npm run preview
```

## 🌐 部署与上线说明

本项目为纯静态产物，支持部署至任意现代化 Web 服务器或静态托管平台：

### 推荐部署方案：
- **Cloudflare Pages / Vercel**: 导入 GitHub 仓库，构建命令填 `npm run build`，输出目录填 `dist` 即可全自动 CI/CD。
